Student Management System - Pro Frontend

Features:
- Login + Register (localStorage demo)
- Dashboard, Add/Edit/Delete students
- Analytics and leaderboard
- Light/Dark theme
- Mobile hamburger drawer navigation
- CSV export
- Recent activity
- Responsive mobile UI
- Profile picture and local profile settings

Important: This is a frontend-only demo. Data is stored in browser localStorage.
It is not a secure production authentication/database system.

APP INSTALL / PWA
This version includes the supplied Naveen app icon, favicon, PWA manifest,
and service worker. On GitHub Pages/HTTPS, open the site in Android Chrome.
Use the "Install App" button when shown, or Chrome menu > Install app.
